# Expense Tracker

## Project Description
Expense Tracker is a simple web application developed using Python Flask, HTML, and CSS. It helps users record and manage their daily expenses.

## Features
- Add new expenses
- View recent transactions
- Calculate total expenses automatically
- Edit existing expenses
- Delete expenses
- Categorize expenses
- Store expense data in a JSON file
- Validate expense amounts

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JSON

## Installation and Setup

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Flask:

```bash
python -m pip install flask
```

5. Run the application:

```bash
python app.py
```

6. Open this address in your browser:

```text
http://127.0.0.1:5000
```

## Data Storage
Expense details are stored locally in `expenses.json`.

## Purpose
This project was developed as a beginner-friendly web development project to practice Python Flask, HTML, CSS, and basic data management.
